# Члан 142.
Централна изборна комисија записнички доставља изборни материјал Изборним комисијама регионалних лекарских комора најкасније 96 часова пре дана одржавања избора.
Изборне комисије регионалних лекарских комора записнички предају изборни материјал бирачким одборима са своје територије најкасније 72 сата пре дана одржавања избора.

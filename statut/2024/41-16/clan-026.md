# Члан 26.
Огранак Коморе предлаже своје представнике из редова чланова Скупштине Коморе за чланове:
1. Управног одбора коморе и то по једног из сваког Већа;
2. Надзорног одбора коморе и то по једног из сваког Већа;
3. Одбора Већа и то по једног из сваког Већа;
4. Извршног одбора огранка и то по три из сваког Већа;
Огранак Коморе предлаже своје представнике из редова чланова Коморе са територије Огранка:
1. Етичког одбора коморе и то по једног из сваког Већа;
2. Комисије за посредовање Огранка и то по три из сваког Већа;
3. Суд части првог степена и то по два из сваког Већа;
4. Суд части другог степена и то по једног из сваког Већа.
Чланови Огранка коморе из Већа запослених стоматолога у државним установама предлажу чланове органа из свог Већа.
Чланови Огранка Коморе из Већа приватне праксе предлажу чланове органа из свог Већа.

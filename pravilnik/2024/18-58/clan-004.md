# Члан 4.
Програм рада има следећу структуру:
1) Увод
2) Делатност установе социјалне заштите из члана 2. став 2. овог правилника
3) Организациона структура
4) Кадровска структура
5) Организација рада
6) План стручног усавршавања запослених
7) Планиране програмске и пројектне активности
8) Планиране инвестиционе активности
9) Финансијски план
10) План развоја нових услуга.

# Члан 18.
Трајање појединих делова царинске униформе и радних одела је:
1. јакна 2 у 1 (један комад) - две године
2. софтшел прслук јакна (један комад) - две године
3. панталоне зимске мушке (два комада) - две године;
4. панталоне зимске женске (два комада) - две године;
5. сукња зимска (два комада) - две године;
6. сако зимски мушки (један комад) - две године;
7. сако зимски женски (један комад) - две године
8. панталоне летње мушке (два комада) - две године;
9. панталоне летње женске (два комада) - две године;
10. сукња летња (два комада) - две године;
11. сако летњи мушки (један комад) - две године;
12. сако летњи женски (један комад) - две године
13. еполете (један пар) - две године;
14. кошуља дугих рукава (четири комада) - једна година;
15. кошуља кратких рукава (четири комада) - једна година;
16. кравата мушка (два комада) - две године;
17. марама женска (два комада) - две године;
18. кожне рукавице (један пар) - три година;
19. ципеле полудубоке зимске мушке (један пар) - две године;
20. ципеле полудубоке зимске женске (један пар) - две године;
21. ципеле плитке летње мушке (један пар) - две године;
22. ципеле плитке летње женске (један пар) - две године;
23. комбинезон (један комад) - две године;
24. поло мајица кратких рукава (четири комада) - једна година;
25. поло мајица дугих рукава (четири комада) - једна година;
26. капа (један комад) - три године;
27. качкет (један комад) - три године;
28. кожни каиш (један комад) - пет година.
Трајање појединих делова царинске униформе за царинске службенике из члана 15. ст. 1. и 2. овог правилника је двоструко дуже од периода трајања из става 1. овог члана.

# Члан 6.
Ималац дозволе дужан је да обезбеди јављање на позив у најкраћем могућем року.
Ималац дозволе дужан је да мери време одзива оператера, као време од звука контроле позива до тренутка јављања оператера броја из опсега који почиње бројем 116.
Просечно време одзива за 90% позива треба да буде мање од седам секунди за број 116000, док за остале бројеве из опсега који почиње бројем 116 ово време треба да буде краће од 15 секунди.
Подаци из става 2. овог члана достављају се Регулатору најмање једном годишње или на захтев Регулатора.

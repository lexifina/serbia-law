РАЗВРСТАВАЊЕ КТЖ ПРЕДМЕТА ПО КАТЕГОРИЈАМА СЛОЖЕНОСТИ ЗА ВИША ЈАВНА ТУЖИЛАШТВА И АПЕЛАЦИОНА ЈАВНА ТУЖИЛАШТВА
# Члан 53о
Предмети прве категорије су предмети код којих збир бодова по општим критеријумима за вредновање предмета по сложености износи 3 бода.
Предмети друге категорије су предмети код којих збир бодова по општим критеријумима за вредновање предмета по сложености износи 4 до 6 бодова.
Предмети треће категорије су предмети код којих збир бодова по општим критеријумима за вредновање предмета по сложености износи више од 6 бодова.

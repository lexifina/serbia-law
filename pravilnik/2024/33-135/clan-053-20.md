РАЗВРСТАВАЊЕ МП ПРЕДМЕТА ПО КАТЕГОРИЈАМА СЛОЖЕНОСТИ ЗА ЈАВНО ТУЖИЛАШТВО ЗА ОРГАНИЗОВАНИ КРИМИНАЛ, ЈАВНО ТУЖИЛАШТВО ЗА РАТНЕ ЗЛОЧИНЕ И ПОСЕБНО ЈАВНО ТУЖИЛАШТВО ЗА ВИСОКОТЕХНОЛОШКИ КРИМИНАЛ
# Члан 53р
Предмети прве категорије су предмети који се по посебним критеријумима за вредновање МП предмета по сложености предмета бодују са 1 бодом.
Предмети друге категорије су предмети који се по посебним критеријумима за вредновање МП предмета по сложености предмета бодују са 2 бода.
Предмети треће категорије су предмети који се по посебним критеријумима за вредновање МП предмета по сложености предмета бодују са 3 бода.

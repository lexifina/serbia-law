# Члан 7.
Уколико привредно друштво резидент Републике Србије које је стекло имовинско право из члана 2. овог правилника у случају отуђења или уступања тог права на начин из члана 6. овог правилника, не обавести обвезника у року из члана 6. ст. 1. и 6. овог правилника, односно уколико обвезник не обавести Пореску управу о губитку права на пореско ослобођење у року из члана 6. став 4. овог правилника, Пореска управа по службеној дужности утврђује пореску обавезу по основу капиталног добитка.

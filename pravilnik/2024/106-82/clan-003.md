# Члан 3.
Упис података у Регистар Министарство врши по службеној дужности.
Подаци из Регистра се објављују јавно, на интернет страници Министарства.
Привредна друштва, односно огранци привредних друштава, који су уписани у Регистар, дужни су да писаним путем обавесте Министарство о свакој промени података из Регистра, у року од осам дана од дана настале промене, уз достављање одговарајуће документације.

# Члан 12.
За наплату чекова по текућим рачунима грађана, корисник јавних средстава Управи подноси:
1) чекове грађана,
2) спецификацију чекова по текућим рачунима, по трасатима.
Са примљеним чековима из става 1. овог члана, Управа поступа у складу са одлуком Народне банке Србије којом се уређује обављање међубанкарског обрачуна чекова по текућим рачунима грађана.

# Члан 24.
Корисник подстицаја из члана 2. тачка 1) овог правилника у року од годину дана од дана закључења уговора из члана 23. овог правилника доставља Управи извештај о реализацији пројекта који садржи податке којима доказује да је спровео све планиране активности, као и доказе о наменском коришћењу средстава остварених по основу подстицаја.
Корисник подстицаја из члана 2. тач. 2)-9) овог правилника по реализацији пројекта, у складу са уговором из члана 23. овог правилника, доставља Управи извештај о реализацији пројекта који садржи податке којима доказује да је спровео све планиране активности, као и доказе о наменском коришћењу средстава.

# Члан 8.
Као доказ о оправданости захтева из члана 2. тачка 2) овог правилника за странца који је пореклом из Републике Србије, прилаже се, односно прибавља се доказ о пореклу из Републике Србије (извод из матичне књиге рођених за подносиоца захтева, извод из матичне књиге рођених за једног или оба родитеља подносиоца захтева).

# Члан 33.
Испитни задаци за стицање звања брокера, по правилу, садрже:
1) тест питања отвореног и/или затвореног типа за чије решавање је, по правилу, предвиђено два минута по питању;
2) квантитативне захтеве - задаци, проблеми и сл. отвореног и/или затвореног типа за чије решавање је, по правилу, предвиђено пет минута по задатку.
Испитни задатак из испитне области Правни оквир функционисања финансијских тржишта садржи само тест питања.

# Члан 5.
Подносилац захтева из члана 3. овог правилника преузима дозволу након враћања претходно преузетих дозвола које су правилно искоришћене за превоз за који су додељене.
Изузетно од става 1. овог члана, дозвола се преузима и када подносилац захтева из члана 3. овог правилника није вратио дозволе преузете по последњем претходно поднетом захтеву, од чијег преузимања није протекло више од 30 дана, у случају да је број дозвола из члана 2. тачка 2) овог правилника већи од броја захтеваних дозвола.
У случају из става 2. овог члана, уз захтев из члана 3. овог правилника се достављају међународни товарни лист, јединствена царинска исправа, као и транзитни пратећи документ ТАД који се односе на додељене дозволе по последњем претходно поднетом захтеву.
Број дозвола које се преузимају на основу захтева из члана 3. став 1. овог правилника, за дозволе из члана 2. тач. 3)-5) овог правилника, не може бити већи од две дозволе по теретном возилу чија носивост, укључујући приколице, не прелази 3,5 тона, односно једне дозволе по теретном возилу одговарајуће надградње, али не мањи од једне дозволе по одређеном контингенту појединачних дозвола.
Број дозвола по теретном возилу, односно по одређеном контингенту појединачних дозвола из става 3. овог члана, утврђује се на основу броја преосталих дозвола из члана 2. тач. 3)-5) овог правилника.
Број дозвола које се преузимају на основу захтева из члана 3. став 1. овог правилника, у случају међународног билатералног и транзитног превоза за сопствене потребе, не може бити већи од броја возила за која је поднет захтев.

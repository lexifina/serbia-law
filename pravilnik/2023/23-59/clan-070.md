# Члан 70.
Кандидат за упис у музичку школу из члана 68. овог правилника положио је пријемни испит ако је остварио најмање 60 бодова на писменом испиту из солфеђа, 60 бодова на усменом испиту из солфеђа и 60 бодова на тесту из теорије музике.
Кандидат који положи испит из солфеђа из члана 66. овог правилника (солфеђо А), сматра се да је положио усмени испит из солфеђа из члана 68. став 1. тачка 2) овог члана.

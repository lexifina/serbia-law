# Члан 5.
Поморац у звању поручника трговачке морнарице полаже, поред предмета из члана 4. став 2. овог правилника, још и испит из енглеског језика.
Испит из енглеског језика обухвата основе енглеског језика, конверзацију и познавање на енглеском језику поморске терминологије у вези са маневрисањем бродом.

# Члан 24.
За свако лежиште са утврђеним резервама гасова категорије А, B и C1 приказују се, поред резерви угљоводоничних гасова, и резерве других природних гасова из члана 4. став 4. овог правилника ако су од привредног значаја, а израчунавају се по њиховом процентном садржају у утврђеним резервама гаса.
Утврђење резерве гаса у лежишту умањују се за израчунату количину утврђених резерви неугљоводоничних гасова.

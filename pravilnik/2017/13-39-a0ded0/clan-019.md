# Члан 19.
Захтев из члана 10. тачка 9) овог правилника, поред података из Обрасца О-9 - Захтев за расподелу и коришћење средстава Фонда, ради финансирања послова из члана 3. тачка 6) овог правилника, садржи и:
1) извод из регистра надлежног органа;
2) оверену копију извода из статута из које се утврђује да се циљеви, послови, односно делатности подносиоца захтева остварују у области у којој се програм реализује;
3) детаљан опис програма.

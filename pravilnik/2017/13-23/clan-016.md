# Члан 16.
У случају да девизни налог и/или документација нису у складу са прописима, односно не испуњавају услове режимске контроле, Народна банка Србије одбија налог и о разлогу одбијања обавештава Управу, која то обавештење прослеђује корисницима јавних средстава.
Корисник јавних средстава у случају из става 1. овог члана нема могућност да исправља девизни налог по основу достављене документације.

# Члан 23.
Извештај процесирања ГНСС мерења, за сваки обрађени вектор садржи:
1) назив тачака између којих су одређене координатне разлике;
2) вредности координатних разлика;
3) оцену стандарда јединице тежине;
4) коваријациону матрицу одређених координатних разлика;
5) тип решења, односно информацију о употребљеном рачунарском алгоритму.

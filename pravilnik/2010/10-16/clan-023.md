# Члан 23.
Осигурано лице врши избор лекара из члана 19. овог правилника, по правилу, на период од најмање једне календарске године. Осигурано лице може променити изабраног лекара и пре истека периода на који га је изабрало.
Ако осигурано лице из става 1. овог члана, по истеку календарске године, настави да користи здравствену заштиту код истог изабраног лекара, сматра се да је извршило избор лекара за наредну календарску годину, без попуњавања обрасца изјаве из члана 24. овог правилника.

# Члан 3.
Здравствени преглед лица које је преболело трбушни тифус обухвата бактериолошки преглед столице и мокраће.
Бактериолошки преглед из става 1. овог члана врши се три пута. Први преглед врши се по истеку седам дана од дана престанка лечења, а остали прегледи - у размаку од најмање 24 часа од претходног прегледа.
Ако су резултати прегледа из става 2. негативни, врши се поновни преглед по истеку шест месеци од последњег негативног бактериолошког прегледа.

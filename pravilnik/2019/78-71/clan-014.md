# Члан 14.
Кандидат који је из једног предмета добио оцену "није положио" упућује се на поправни испит из тог предмета.
Поправни испит се полаже у року који одреди Комисија, а који не може бити краћи од месец дана ни дужи од три месеца од дана полагања усменог дела испита.
Поправни испит је могуће полагати једном.

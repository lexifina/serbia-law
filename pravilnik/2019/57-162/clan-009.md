Општи захтев
# Члан 9.
У оквиру Система за размену података надлежни орган успоставља услугу електронске управе која омогућава непосредно обраћање органу ради увида, прибављања, обрађивања и уступања, односно достављања података из регистара (Општи захтев).
Ако орган надлежан за вођење регистра нема успостављен веб сервис за преузимање података из регистра, орган који води поступак непосредно се обраћа путем услуге електронске управе из става 1. овог члана.
Овлашћена службена лица из члана 5. став 4. овог правилника користе услуге електронске управе из става 1. овог члана у поступцима које воде, без претходног подношења захтева из члана 6. овог правилника.

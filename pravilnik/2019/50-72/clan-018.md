# Члан 18.
Право на полагање усменог дела царинског испита стичу кандидати који су положили писмени део царинског испита.
За усмени део царинског испита израђује се списак питања из сваког предмета из чл. 4. и 5. овог правилника.
Усмени део царинског испита кандидат полаже одговарањем на три питања из сваког испитног предмета.
Предмет Информациони системи царинске службе се полаже усмено презентовањем на рачунару.

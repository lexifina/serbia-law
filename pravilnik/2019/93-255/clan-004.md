# Члан 4.
Када се слање узорка обавља превозом кроз подручје друге државе (у даљем тексту: транзитна држава), Национална контактна тачка извештава о планираном слању националну контактну тачку транзитне државе. У ту сврху, свакој транзитној држави доставља се примерак попуњеног Обрасца пре отпочињања слања.

# Члан 2.
Програм полагања стручног испита састоји се из општег и посебног дела.
Општи део програма из става 1. овог члана садржи градиво из следећих предмета:
1) Уставно уређење,
2) Систем државне управе.
Посебан део програма из става 1. овог члана садржи градиво из следећих предмета:
1) Систем друштвене бриге о деци;
2) Методика социјалног рада са појединцем;
3) Методика групног социјалног рада;
4) Социјални рад у локалној заједници;
5) Системи социјалне сигурности.
Посебан део програма из предмета - Систем друштвене бриге о деци обухвата и писмени рад.

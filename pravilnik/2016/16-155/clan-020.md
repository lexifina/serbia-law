# Члан 20.
Структура елемента позив на број одобрења, код уплате јавних прихода из члана 18. став 2. овог правилника* од стране великих пореских обвезника код Центра за велике пореске обвезнике садржана је у Прилогу 2, редни број 3.
Позив на број одобрења, састоји се из четири дела, и то:
1) двоцифрени контролни број по моделу 97;
2) троцифрени број општине, града, аутономне покрајине или Републике (колона 3 Прилога 3);
3) порески идентификациони број;
4) петоцифрени број економске класификације из колоне 2 Прилога 1, и то почев од друге до шесте цифре.

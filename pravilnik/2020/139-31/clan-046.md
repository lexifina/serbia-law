Класа 6: Приходи
# Члан 46.
На рачунима групе 60 - Приходи од провизија, исказују се приходи од пружања услуга Централног регистра.
На рачуну 600 - Приходи по основу провизија од приступа, инсталације и одржавања апликације Централног регистра исказују се приходи по основу приступа информационом систему Централног регистра од стране његових чланова, као и инсталација и одржавање апликације Централног регистра коју користе чланови.
На рачуну 601 - Приходи по основу провизија од отварања и гашења рачуна финансијских инструмената и уписа финансијских инструмената у Централни регистар исказују се приходи по основу отварања, затварања, односно гашења рачуна финансијских инструмената, као и потраживања по основу уписа финансијских инструмената у Централни регистар.
На рачуну 602 - Приходи по основу провизија од послова са финансијским инструментима исказују се приходи по основу послова са финансијским инструментима који се односе на промену власништва, као и по основу послова са финансијским инструментима који се не односе на промену власништва.
На рачуну 603 - Приходи по основу провизија од корпоративних радњи исказују се приходи по основу исплате купона, ануитета и главнице имаоцу дужничких хартија од вредности, исплате дивиденде акционарима, издавања јединствене евиденције акционара, исписа акција по основу промене правне форме, стечаја, ликвидације или статусне промене акционарског друштва, као и других корпоративних радњи.
На рачуну 604 - Приходи по основу накнада за електронске поруке, исказују се приходи по основу слања електронских порука члановима, као и по основу промене података у порукама и закључницама на захтев чланова.
На рачуну 605 - Приходи по основу накнада за активирање ванредних процедура, исказују се приходи по основу активирања средстава Гарантног фонда, као и активирања процедура принудне продаје, односно куповине хартија од вредности.
На рачуну 606 - Приходи по основу провизија од достављања извештаја, исказују се приходи по основу достављања података о стању и променама на рачуну законитих ималаца, достављања података по захтевима за информације од јавног значаја, односно захтевима надлежних органа, као и израде посебних извештаја..
На рачуну 607 - Приходи по основу провизија од обављања осталих послова исказују се приходи по основу осталих послова Централног регистра.

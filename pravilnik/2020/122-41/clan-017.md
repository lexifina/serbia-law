# Члан 17.
Завод, на основу мишљења јединице локалне самоуправе из члана 16. ст. 4. и 5. овог правилника, предлаже Влади промену границе катастарске општине, у складу са чланом 43. став 2. Закона.
По доношењу одлуке Владе о промени границе катастарске општине извођач радова обележава границу катастарске општине постављањем геодетских белега.

# Члан 13.
Под ознаком АОП 3015 - Нето прилив готовине из пословних активности, исказује се разлика између позиција под ознаком АОП 3001 - Приливи готовине из пословних активности и АОП 3006 - Одливи готовине из пословних активности.
Под ознаком АОП 3016 - Нето одлив готовине из пословних активности, исказује се разлика између позиција под ознаком АОП 3006 - Одливи готовине из пословних активности и АОП 3001 - Приливи готовине из пословних активности.

# Члан 33.
Индуктивна петља, као и високо фреквенцијални излаз из предајника, треба да су симетрични. Код индуктивног система позивања лица који ове услове не задовољава мора напон сметњи на излазу VF предајника према маси, односно према шасији апарата бити за 12dB мањи него што је то предвиђено југословенским стандардом JUS N.N0.900, који је донесен Решењем о југословенским стандардима из области радио-дифузије ("Службени лист СФРЈ", бр. 30/69).

# Члан 50.
Селективност за суседни сигнал радио-пријемника не сме бити мања од вредности одређених у табели бр. 4.
Табела бр. 4.
Одступање фреквенције нежељеног улазног сигнала у односу на носећу (референтну) фреквенцију жељеног улазног сигнала
Селективност за суседни сигнал
-1 kHz и +4 kHz
40 dB
-2 kHz и +5 kHz
50 dB
-5 kHz и +8 kHz
60 dB
Испитивање радио-пријемника, ради провере усаглашености са вредностима из табеле бр. 4, врши се тако што се ниво жељеног улазног сигнала поставља на ниво осетљивости мерен према условима из члана 48. овог правилника, а ниво нежељеног амплитудски модулисаног улазног сигнала (30% модулација са фреквенцијом од 400 Hz) подешава док се однос С+Ш+И/Ш+И не смањи за 6 dB.

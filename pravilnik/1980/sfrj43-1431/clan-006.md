# Члан 6.
Матични број одређује се на основу података садржаних у одлуци надлежног органа којом је странцу признат неки од статуса наведених у члану 2. овог правилника и броја регистра републике, односно аутономне покрајине.
Контролни број одређује се електронским рачунаром по Упутству о начину одређивања контролног броја јединственог матичног броја грађана по модулу 11 ("Службени лист СФРЈ", број 36/77).
Савезни орган управе надлежан за унутрашње послове доставиће, на захтев органа надлежног за одређивање матичног броја, један примерак одлуке којом се странцу признаје неки од статуса из члана 2. овог правилника.

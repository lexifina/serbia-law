# Члан 2.
Испит се полаже по програму прописаном овим правилником који се састоји од следећих испитних области:
1) Основног познавања транспорта опасног терета;
2) Специјалистичке области за транспорт у цистернама;
3) Специјалистичке области за транспорт експлозивних материја и предмета класе 1 АДР;
4) Специјалистичке области за транспорт радиоактивних материја класе 7 АДР;
5) Обнове знања из Основног познавања транспорта опасног терета;
6) Обнове знања из Специјалистичке стручне оспособљености.

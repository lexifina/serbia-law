# Члан 7.
Возач који поседује важећи сертификат о стручној оспособљености за обављање послова возача возила за транспорт опасног терета полаже испит из области Основног познавања транспорта опасног терета током последње године пре истека рока важења сертификата.
Возач полаже испит из области обнове знања из специјалистичке стручне оспособљености за коју има важећи сертификат.

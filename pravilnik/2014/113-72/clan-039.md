# Члан 39.
Спецификација модела је одабир фактора за иницијални модел из групе фактора за које је, сагласно члану 36. овог правилника, утврђено да имају значајан утицај на цене непокретности.
Основа сваког модела је карактеристична непокретност која се одређује дефинисањем вредности одабраних фактора у моделу.

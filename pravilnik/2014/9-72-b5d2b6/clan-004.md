# Члан 4.
Министарство по пријему мишљења Комисије решењем одлучује о захтеву за издавање одобрења за обављање послова посредовања при запошљавању помораца.
Када утврди да подносилац захтева испуњава услове за издавање одобрења, осим услова из члана 2. став 2. тачка 2) овог правилника, министарство обавештава подносиоца захтева о обавези да достави доказ о испуњавању наведеног услова.
Подносилац доставља доказ из става 2. овог члана у року од 15 дана од дана пријема обавештења, након чега министарство доноси решење из става 1. овог члана.
Решење из става 1. овог члана коначно је у управном поступку.

# Члан 2.
Управа царина Пореској управи доставља следеће податке из Јединствене царинске исправе (у даљем тексту: ЈЦИ):
1) тарифну ознаку номенклатуре Царинске тарифе из рубрике 33;
2) трговачки назив робе из рубрике 31;
3) количину робе и јединицу мере из рубрика 35, 38 и 41;
4) земљу порекла робе из рубрике 34;
5) вредност робе за царинске сврхе из рубрика 22, 42, 46 и 47;
6) број ЈЦИ и датум прихватања декларације из рубрике А;
7) податке о увознику (назив, ПИБ, адреса седишта) из рубрике 8;
8) податке о царинској испостави која је спровела поступак из рубрике А;
9) податке о царински одобреном поступку из рубрике 37;
10) све друге податке садржане у јединственој царинској декларацији који су од значаја за примену Закона о порезу на увоз угљенично интензивних производа ("Службени гласник РС", број 109/25).

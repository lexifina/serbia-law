Начин приступања Софтверском решењу
# Члан 3.
Послодавац приступа Софтверском решењу преко веб портала Софтверског решења који представља услугу електронске управе на Порталу е-Управа, на који се пријављује електронском идентификацијом високог нивоа поузданости.
Иницијални приступ Софтверском решењу омогућен је кориснику којем је на Порталу е-Управа додељена корисничка улога "Овлашћено лице органаˮ из члана 2. става 2. тачка 1) овог правилника, односно корисничка улога "Законски заступникˮ из члана 2. става 2. тачка 2) овог правилника, као и кориснику коме је додељена корисничка улога "Рад у систему е-Боловање - Послодавацˮ, односно "Рад са обрачунима у систему е-Боловање - Послодавацˮ.
Приликом приступа из става 2. овог члана, креира се кориснички профил послодавца који садржи следеће податке:
1) пословно име, односно скраћено пословно име;
2) порески идентификациони број (ПИБ);
3) матични број (МБ);
4) јединствени број корисника јавних средстава (ЈБКЈС);
5) адреса седишта;
6) адреса за пријем електронске поште;
7) број наменског рачуна;
8) адреса за пријем електронских обавештења.
Осим података из става 3. овог члана, кориснички профил послодавца може садржати и податак о позиву на број, као и о броју телефона за контакт послодавца.
Подаци из става 3. тач. 1)-6) овог члана преузимају се аутоматизован начин из налога послодавца на Порталу е-Управа, док корисник уноси податке из става 3. тач. 7) и 8) и става 4. овог члана.
Након креирања профила послодавца, корисник може приступити свим функционалностима Софтверског решења.

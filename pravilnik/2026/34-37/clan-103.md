# Члан 103.
Изузетно од одредаба члана 102. овог правилника обавезе и преплате по основу доприноса за обавезно социјално осигурање које испуњавају услове из члана 115б Закона, Пореска управа чува у евиденцији ненаплативих доприноса за обавезно социјално осигурање престалих пореских обвезника.
Евиденција ненаплативих доприноса за обавезно социјално осигурање престалих пореских обвезника садржи податке о ПИБ, називу, односно имену и презимену обвезника брисаног из прописаног регистра, износу дуга, споредних пореских давања, односно преплате по основу доприноса за обавезно социјално осигурање, рачуну за уплату јавних прихода и шифри територије.
Пренос података из пореског рачуноводства у евиденцију ненаплативих доприноса за обавезно социјално осигурање престалих пореских обвезника врши се на основу електронског наменског извештаја, односно на основу решења из члана 23. став 1. тачка 4) Закона књижењем сторна ненаплативог дуга по основу доприноса за обавезно социјално осигурање, на потражној страни рашчлањеног рачуна у класи "1" и дуговној страни аналогног рашчлањеног рачуна у класи "2".
Истовремено, врши се књижење сторно ненаплативог дуга по основу доприноса за обавезно социјално осигурање на дуговној страни аналитичке картице престалог пореског обвезника.
Књижење сторно преплате по основу доприноса за обавезно социјално осигурање престалог пореског обвезника спроводи се на основу електронског наменског извештаја, односно на основу решења из члана 23. став 1. тачка 4) Закона, тако што се врши сторно износа преплате на потражној страни рашчлањеног рачуна у класи "2" и дуговној страни аналогног рашчлањеног рачуна у класи "1".
Истовремено, врши се књижење сторно преплате по основу доприноса за обавезно социјално осигурање на потражној страни аналитичке картице престалог пореског обвезника.
За евидентирање сторна одређују се посебне шифре промена:
1) главној књизи из шифарника АОП:
- 73 - сторно дуга престалог обвезника корисници/сторно дуга престалог обвезника обвезници;
- 82 - сторно преплате престалог обвезника корисници/сторно преплате престалог обвезника обвезници;
2) аналитичким картицама из шифарника АОП:
- 164 - групни сторно ненаплатив дуг по основу доприноса за обавезно социјално осигурање;
- 165 - групни сторно ненаплатива камата по основу доприноса за обавезно социјално осигурање;
- 168 - појединачни сторно ненаплатив дуг по основу доприноса за обавезно социјално осигурање;
- 169 - појединачни сторно ненаплатива камата по основу доприноса за обавезно социјално осигурање;
- 535 - групни сторно преплата по основу доприноса за обавезно социјално осигурање престалих пореских обвезника;
- 536 - појединачни сторно преплата по основу доприноса за обавезно социјално осигурање престалих пореских обвезника.
Извештај о подацима пренетим из пореског рачуноводства у евиденцију ненаплативих доприноса за обавезно социјално осигурање престалих пореских обвезника, сачињава се за календарску годину у року прописаном за сачињавање пореског годишњег извештаја, на Обрасцу ИНДОСО, који је одштампан уз овај правилник и чини његов саставни део (Прилог број 15).
Евиденција из става 2. овог члана води се у електронском облику.

# Члан 22.
По територијалном принципу, чланове Скупштине бирају парламенти привредника регионалних привредних комора, односно парламент привредника привредне коморе главног града.
Чланови Скупштине се бирају из редова чланова парламента привредника, изабраних након доношења одлуке из члана 6. овог правилника.
Одлуку о избору чланова Скупштине парламенти привредника достављају генералном секретару Коморе.

# Члан 15.
Коначну листу изабраних чланова парламенaта привредника по територијалном и гранском изборном принципу утврђује изборна комисија.
У случају да је за члана парламента привредника изабран исти члан Коморе по територијалном и по гранском изборном принципу, члан Коморе постаје члан парламента привредника по основу избора од стране одбора гранског удружења Коморе, а чланство у парламенту привредника по основу територијалног изборног принципа, остварује први следећи кандидат са листе.

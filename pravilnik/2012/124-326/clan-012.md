# Члан 12.
Геометрија објеката базе података ГКИС-а дефинисана је геометријским елементима применом стандарда ISO19107 Географске информације - Просторна шема.
Правила креирања геометријских и тополошких релација између објеката прописана су моделом података.
Провером испуњености правила из става 2. овог члана утврђује се тополошка, геометријска и тематска конзистентност садржаја базе података ГКИС-а.

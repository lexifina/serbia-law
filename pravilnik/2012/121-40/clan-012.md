# Члан 12.
Установљавање географске ознаке врши се ако производња грожђа не премашује максималне дозвољене приносе који износе:
1) 4,5 килограма по чокоту и 13.500 килограма по хектару - за винограде са 3.000 до 4.000 чокота по хектару;
2) 4 килограма по чокоту или 16.000 килограма по хектару - за винограде са преко 4.000 чокота по хектару.
Установљавање ознаке контролисаног географског порекла врши се ако производња грожђа не премашује максималне дозвољене приносе који износе:
1) 2,5 килограма по чокоту и 7.500 килограма по хектару - за винограде са 3.000 до 4.000 чокота по хектару;
2) 2 килограма по чокоту и 8.000 килограма по хектару - за винограде са преко 4.000 чокота по хектару.

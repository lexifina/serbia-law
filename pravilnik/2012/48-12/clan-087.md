# Члан 87.
Соба без купатила, поред опреме из члана 85. став 1. овог правилника мора да има и:
1) најмање два пешкира;
2) чашу у хигијенској фолији по особи;
3) сапун по особи.
Соба без купатила која има умиваоник са текућом топлом и хладном водом, поред опреме из члана 85. став 1. овог правилника мора да има и:
1) огледало са осветљењем;
2) полицу за тоалетни прибор;
3) простирку испред умиваоника;
4) држач пешкира;
5) најмање два пешкира;
6) држач сапуна;
7) сапун по особи;
8) чашу у хигијенској фолији по особи.

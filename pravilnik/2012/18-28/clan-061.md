# Члан 61.
У производњи лекова из крви и крвне плазме хуманог порекла који су намењени за промет у Републици Србији, произвођач са седиштем у Републици Србији мора поштовати начело самодовољности, односно да се у производњи лекова из крви хуманог порекла, у највећој могућој мери, користе залихе крви из Републике Србије.

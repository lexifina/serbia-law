# Члан 61.
Кефир се ставља у промет као:
1) кефир, и мора да садржи:
- најмање 3,0 % млечне масти,
- најмање 8,2 % суве материје млека без масти;
2) кефир од делимично обраног млека, и мора да садржи:
- мање од 3,0 % а више од 0,5 % млечне масти,
- најмање 8,2 % суве материје млека без масти;
3) кефир од обраног млека, и мора да садржи:
- највише 0,5 % млечне масти,
- најмање 8,2 % суве материје млека без масти.

# Члан 44.
Јогурт се ставља у промет као:
1) јогурт, и мора да садржи:
- најмање 3,0 % млечне масти,
- најмање 8,2 % суве материје млека без масти;
2) јогурт од делимично обраног млека, и мора да садржи:
- мање од 3,0 % а више 0,5 % млечне масти,
- најмање 8,2 % суве материје млека без масти;
3) јогурт од обраног млека, и мора да садржи:
- највише 0,5 % млечне масти,
- најмање 8,2% суве материје млека без масти.

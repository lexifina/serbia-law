# Члан 12.
Кандидат који је положио посебан део стручног испита, а није положио општи део стручног испита, може полагати поправни испит из општег дела стручног испита у року који не може бити краћи од три месеца од дана када је испит полагао.
Кандидат који није положио посебан део стручног испита, приликом следећег пријављивања стручног испита пријављује нову тему стручног рада.

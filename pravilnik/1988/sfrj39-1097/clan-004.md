# Члан 4.
Коњима сумњивим на инфективну анемију сматрају се коњи који су у последња три месеца били у директном или индиректном додиру са копитарима зараженим том болешћу.
Коњи сумњиви на обољење морају се подвргнути дијагностичком испитивању из члана 2. овог правилника, тако да се преглед узорака њихове крви врши највише три пута. Трећи преглед врши се по истеку четири месеца од додира са оболелим копитарима, ако приликом претходних прегледа није утврђена позитивна реакција.
Сумњиви коњи сматраће се незараженим ако по истеку четири месеца од додира са оболелим копитарима резултат прегледа буде негативан.

# Члан 231.
Минска поља це, по правилу, активирају електричним паљењем, при чему се електрични детонатори морају причврстити на мрежу детонирајућег штапина и изван минског поља.
Ако се мине пале искључиво електричним детонаторима без детонирајућег штапина, за сваку минску бушотину морају се употребити по два електрична детонатора (на дну минске бушотине и код чепа од инертног материјала).

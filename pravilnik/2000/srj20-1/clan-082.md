# Члан 82.
Једињења гвожђа, у смислу овог правилника, су:
1) Гвође (Fe);
2 ) гвожђе - (II) - карбонат FeCO3;
3) гвожђе - (II) - хлорид, тетрахидрат FeCl x 4H2O;
4) гвожђе - (III) - хлорид, хексахидрат FeCl3 x 6H2O;
5) гвожђе - (II) - цитрат, хексахидрат Fe3(C6H5O7)2 x 6H2O;
6) гвожђе - (II) - фумарат FeC4H2O4;
7) гвожђе - (II) - лактат, трихидрат Fe(C3H5O3)2 x 3H2O;
8 гвожђе - (III) - оксид FeO3;
9) гвожђе - (II) - сулфат, хептахидрат FeSO4 x 7H2O;
10) гвожђе - (II) - сулфат, монохидрат FeSO4 x H2O.

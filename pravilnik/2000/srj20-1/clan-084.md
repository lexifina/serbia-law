# Члан 84.
Једињења кобалта, у смислу овог правилника, су:
1) Кобалт (Co);
2) кобалт - (II) - ацетат, тетрахидрат Co(CH3COO)2 x 4H2O;
3) базни кобалт - (II) - карбонат, монохидрат 2CoCO3 x 3Co(OH)2 x H2O;
4) кобалт - (II) - хлорид, хексахидрат CoCl x 6H2O;
5) кобалт - (II) - нитрат, хексахидрат Co(NO3)2 x 6H2O;
6) кобалт - (II) - сулфат, монохидрат CoSO4 x H2O;
7) кобалт - (II) - сулфат, хептахидрат CoSO4 x 7H2O.

# Члан 86.
Једињења мангана, у смислу овог правилника, су:
1) Манган (Mn);
2) манган - (II) - карбонат MnCO3;
3) манган - (II) - хлорид, тетрахидрат MnCl2 x 4H2O;
4) манган - (II) - оксид MnO;
5) манган - (III) - оксид Mn2O3;
6) секундарни манган - (II) - фосфат, трихидрат MnHPO4 x 3H2O;
7) манган - (II) - сулфат, тетрахидрат MnSO4 x 4H2O;
8) манган - (II) - сулфат, монохидрат MnSO4 x H2O.

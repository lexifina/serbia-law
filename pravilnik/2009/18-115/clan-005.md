# Члан 5.
Власник или држалац пријемчивих животиња код којих постоји сумња на болест плавог језика, дужан је да предузме наређене мере, у складу са одредбама члана 4. овог правилника.
Мере из члана 4. тач. 2), 3), 4) и 8) овог правилника примењују се на пријемчиве животиње које живе слободно у природним резерватима.
Мере из члана 4. овог правилника примењују се док се не искључи сумња на болест плавог језика.

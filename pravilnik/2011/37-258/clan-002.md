# Члан 2.
Процена безбедности хемикалије састоји се од четири поступка:
1. процене опасности по здравље људи;
2. процене опасности по здравље људи на основу физичких и хемијских својстава;
3. процене опасности по животну средину;
4. процене да ли супстанца испуњава критеријуме за идентификацију као перзистентна - биоакумулативна - токсична (у даљем тексту: ПБТ) или веома перзистентна - веома биоакумулативна (у даљем тексту: вПвБ).

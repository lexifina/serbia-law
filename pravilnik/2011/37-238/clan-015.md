# Члан 15.
Оцена радијационог утицаја из члана 13. став 4. овог правилника даје се на основу:
1. резултата истраживања из члана 14. овог правилника;
2. путева ширења радиоактивних ефлуената у животну средину;
3. утврђивања критичних путева ширења радиоактивних ефлуената у животној средини;
4. утврђивања критичне групе становништва односно најизложенијег појединца.
Ограничења која произлазе из оцене из става 1. овог члана представљају пројектне основе за системе задржавања и прочишћавања радиоактивних ефлуената нуклеарног објекта код погонских стања.

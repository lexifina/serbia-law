4. Лек произведен из крви
# Члан 86.
На спољњем паковању лека који се производи из крви, односно из компонената крви морају бити унети подаци у складу са чланом 6. овог правилника.
Поред ових података, на спољњем паковању лека који се производи из крви, односно из компонената крви наводи се реченица: "Лек је произведен из крви. За детаљније информације погледати упутство за лек".

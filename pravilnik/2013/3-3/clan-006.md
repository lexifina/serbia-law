Локалитет
# Члан 6.
Сорта се испитује на више локалитета, а број локалитета зависи од одговарајућег типа из члана 4. овог правилника.
Огледи за сорте уљаног типа из члана 4. став 2. тач. 1) и 2) овог правилника изводе се на најмање четири локалитета.
Огледи за сорте уљаног типа из члана 4. став 2. тачка 3) овог правилника и за конзумни тип изводе се на најмање три локалитета.

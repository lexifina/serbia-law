# Члан 2.
Република Србија - Министарство финансија (у даљем тексту: Министарство), преко Управе за трезор, извршиће уплату новчане помоћи лицима из члана 2. Закона - у износу од два пута по 30 евра у динарској противвредности по званичном средњем курсу динара према евру који утврђује Народна банка Србије на дан ступања на снагу Закона, што на дан ступања на снагу Закона износи 3.527,37 динара (у даљем тексту: новчана помоћ).

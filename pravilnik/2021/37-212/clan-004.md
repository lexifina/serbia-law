# Члан 4.
Мерила за која је у колони 3 "Временски интервали периодичног оверавања мерила (у годинама)" Табеле из члана 2. овог правилника уписана (-) не подлежу периодичном оверавању.
Мерила из Табеле из члана 2. овог правилника која су означена звездицом (*), оверавају се само ако је за та мерила издато уверење о одобрењу типа, односно периодично се оверавају само ако је за та мерила спроведен поступак оцењивања усаглашености са прописаним захтевима.

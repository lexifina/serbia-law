# Члан 5.
Образац ОНПР-И послодавац доставља Пореској управи у року од осам дана од дана заснивања радног односа, односно од дана престанка радног односа новозапосленог лица са инвалидитетом по основу чијег запошљавања стиче право на пореску олакшицу, односно од дана губитка, односно престанка пореске олакшице за то лице.
Податке на Обрасцу ОНПР-И послодавац доставља појединачно за свако лице из члана 4. овог правилника.

# Члан 20.
Регистрација учесника започиње најкасније сат времена пре почетка јавног надметања у складу са условима наведеним у огласу.
Регистрација учесника се завршава наступањем времена које је у огласу наведено за започињање јавног надметања.
Лице које је дошло по истеку времена из става 2. овог члана не може се регистровати, односно стећи статус учесника на јавном надметању.
Сматра се да су испуњени услови за спровођење јавног надметања ако је најмање једно лице стекло статус учесника, ако присуствује поступку јавног надметања.
У случају да нису испуњени услови из става 4. овог члана јавно надметање ће бити проглашено неуспелим.

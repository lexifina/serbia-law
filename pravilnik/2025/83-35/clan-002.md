# Члан 2.
Електронска размена података између Агенције и надлежног државног органа врши се путем стандардних механизама веб сервиса заснованих на протоколу Simple Object Access Protocol (SOAP).
Електронска размена података између Агенције и надлежног државног органа може да се врши и путем заштићене верзије стандардног мрежног протокола File Transfer Protocol (FTP).

# Члан 18.
Рапорт се, по правилу, предаје при уласку у службене просторије организационе јединице, ако је искључена могућност да се са садржајем рапорта упознају непозвана лица. У противном, рапорт се предаје по уласку у службене просторије организационе јединице.
Када је јединица полиције постројена за дочек, поздрављање јединицом и предаја рапорта врши се по прописаном правилу полиције.

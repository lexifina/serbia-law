Класификација прорачунске потребне отпорности на пожар
# Члан 49.
Прорачунска потребна отпорност према пожару erftF класификује се према називној потребној отпорности на пожар на следећи начин:
1) 0 < erftF ≤ 15 min без захтева за отпорност према пожару;
2) 15 < erftF ≤ 30 min мала отпорност према пожару - класа отпорности 30 min;
3) 30 < erftF ≤ 60 min већа отпорност према пожару - класа отпорности 60 min;
4) 60 < erftF ≤ 90 min велика отпорност на пожар - класа отпорности 90 min.
Отпорност према пожару елемената конструкције према класама безбедности од пожара мора одговарати најмање прорачунски потребној отпорности према пожару која не може бити већа од 90 min.
Ако се из прорачуна за класу безбедности од пожара SKb3, добије прорачунска потребна отпорност према пожару већа од 90 min, тада се поступак прорачуна понавља са коригованим подацима потребним за прорачун из члана 33. овог правилника.

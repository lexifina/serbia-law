# Члан 9.
Ако се странац принудно удаљава на начин из члана 8. овог правилника, а из безбедносних разлога је неопходно присуство полицијских службеника у ваздухоплову, принудно удаљење спроводе полицијски службеници који су прошли специјалну обуку за извршење принудног удаљења.
Број полицијских службеника који спроводе принудно удаљење из става 1. овог члана одређује се у сваком појединачном случају, након анализе потенцијалних ризика, а оптималан број треба да буде најмање једнак броју лица чије принудно удаљење се спроводи.
Полицијски службеници који спроводе принудно удаљење из става 1. овог члана нису наоружани.

# Члан 16.
Ради формирања бесконачног ужета, вучно уже привремено постављене вучнице се уплиће дугим уплетом у складу са SRPS стандардима за челичну ужад, при чему је дужина уплета lu = 1.200 d, где је: d = пречник ужета.
Вучно уже привремено постављене вучнице се наставља са највише четири уплета, на најмањем међусобном размаку од 2,5 lu.

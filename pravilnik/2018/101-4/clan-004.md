# Члан 4.
Средства за редовно пословање, сопствени приходи, средства из других извора средстава корисника буџетских средстава Републике и корисника средстава ООСО консолидују се на нивоу КРТ Републике.
Ако се корисник буџетских средстава Републике финансира из буџета различитих нивоа власти, сопствени приходи и средства из других извора тог корисника консолидују се на нивоу трезора према припадности директног корисника буџетских средстава.

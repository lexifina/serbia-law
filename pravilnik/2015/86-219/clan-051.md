# Члан 51.
Количина средства за одоризацију мора бити толика да омогућава препознавање присуства гаса у ваздуху у количини већој од петине доње границе експлозивности у свакој тачки дистрибутивног гасоводног система у коме је обавезна одоризација.
Потребна концентрација одоранта етил меркаптана у најудаљенијој тачки дистрибутивног гасоводног система је 9-21 mg/m3 при нормалним условима.
Потребна концентрација одоранта тетрахидротиофена у најудаљенијој тачки дистрибутивног гасоводног система (THT) је 12-23 mg/m3 при нормалним условима.

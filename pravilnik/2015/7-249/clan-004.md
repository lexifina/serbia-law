# Члан 4.
Комора извршитеља је дужна да одговори на захтев извршног повериоца у складу са Законом о извршењу и обезбеђењу.
Уколико је број предлога за извршење наведених у захтеву извршног повериоца мањи од броја извршитеља надлежних за поступање, одређивање извршитеља по првом следећем захтеву извршног повериоца започеће од првог наредног извршитеља уписаног у Именик извршитеља после извршитеља који је последњи одређен.

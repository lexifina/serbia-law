# Члан 72.
Избор везних тачака при мануелном одређивању треба да буде такав да омогућава њихову недвосмислену идентификацију и поуздано мерење њихових сликовних координата на снимцима.
Минимални број везних тачака код мануелног одређивања износи шест тачака по стереомоделу, тако да по једна тачка буде у угловима стереомодела и по једна у близини пројекционих центара снимака који чине стереомодел.

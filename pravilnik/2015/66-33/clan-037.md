# Члан 37.
Осуђени који је накнадно разврстан у групу В1 из разлога предвиђених чланом 36. овог правилника може бити накнадно разврстан у групу Б2 по истеку најмање једне четвртине преосталог дела казне.
Осуђени који је накнадно разврстан у групу Б1 из разлога предвиђених чланом 36. овог правилника може бити накнадно разврстан у групу А2 по истеку најмање једне петине преосталог дела казне.
Накнадно разврставање из групе В2 у В1, Б2 у Б1 и А2 у А1, није условљено дужином преосталог дела казне.

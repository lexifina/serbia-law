ОДРЕДБЕ КОЈЕ НИСУ УНЕТЕ У "ПРЕЧИШЋЕН ТЕКСТ" ПРАВИЛНИКА
Правилник о изменама Правилника о лиценци за обављање енергетске делатности и сертификацији: "Службени гласник РС", број 94/2026-4
Члан 3.
Овај правилник ступа на снагу наредног дана од дана објављивања у "Службеном гласнику Републике Србије".
Прилози
НАПОМЕНА ИЗДАВАЧА:
Престају да важе одредбе Правилника у обрасцима, у делу у ком се установљава обавеза употребе печата у пословању друштава и предузетника, даном почетка примене члана 160. Закона о изменама и допунама Закона о привредним друштвима ("Службени гласник РС", број 44/2018), односно 1. октобра 2018. године (види члан 160. Закона - 44/2018-27).
Правилником о изменама и допунама Правилника о лиценци за обављање енергетске делатности и сертификацији ("Службени гласник РС", број 83/2021) општи обрасци ОО1 и ОО2 и посебни обрасци ПО 9, ПО 10, ПО 11, ПО 12, ПО 13, ПО 14, ПО 15, ПО 16, ПО 17, ПО 18, ПО 19, ПО 20, ПО 21 и ПО 22 замењени су општим обрасцима ОО1 и ОО2 и посебним обрасцима ПО 9, ПО 10, ПО 11, ПО 12, ПО 13, ПО 14, ПО 15, ПО 16, ПО 17, ПО 18, ПО 19, ПО 20, ПО 21 и ПО 22. Наведеним правилником додати су посебни обрасци ПО 23 и ПО 24 (види члан 14. Правилника - 83/2021-45).

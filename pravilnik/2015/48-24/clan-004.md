# Члан 4.
Приликом доношења одлуке о су/финансирању израде планског документа примењују се следећи критеријуми:
1) приоритетност доношења планског документа;
2) број становника јединице локалне самоуправе;
3) површина територије јединице локалне самоуправе;
4) степен развијености јединице локалне самоуправе;
5) буџетска средства која је јединица локалне самоуправе определила за израду предметног планског документа у години подношења захтева;
6) наменско трошење средстава додељених по овом основу.

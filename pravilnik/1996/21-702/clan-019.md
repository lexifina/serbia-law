# Члан 19.
Посебни део стручног испита обухвата:
1) Писмени део испита:
- израда писменог стручног рада односно пројекта.
2) Усмени део испита:
- одбрана стручног рада;
- провера познавања закона, техничких прописа, норматива, стандарда и других прописа из области из које кандидат полаже стручни испит;

# Члан 12.
У члану 42. после става 2. додају се нови ст. 3 и 4. који гласе:
„Изузетно од става 2. актом из става 2. овог члана може се одредити да је линијски превоз у интегрисаном тарифном систему за све кориснике услуге на територији Града Београда бесплатан.
У случају из става 3. овог члана, начела и елементи за одређивање цене услуге из става 2. овог члана, не примењују се.”.

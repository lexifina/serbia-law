# Одлука о некатегорисаним путевима на територији градске општине Гроцка

Акти градских општина Гроцка · 73/2015 · published 2015-12-03.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2015/73-2015.pdf#page=18) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Обавезује се ЈП "Дирекција за изградњу општине Гроцка" да у року од шест месеци од дана ступања на снагу ове одлуке сачини евиденцију некатегорисаних путева на територији градске општине Гроцка. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

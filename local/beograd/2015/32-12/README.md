# Пословник Скупштине Градске општине Чукарица

Акти градских општина Чукарица · 32/2015 · published 2015-06-15.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2015/32-2015.pdf#page=12) · [Record](tekst.md)

Date basis: narednog dana od objavljivanja; source clause: Даном ступања на снагу овог пословника престаје да важи Пословник Скупштине градске општине Чукарица ("Службени лист Града Београда", број 61/2014 – пречишћен текст). Овај пословник ступа на снагу наредног дана од дана објављивања у "Службеном листу Града Београда".

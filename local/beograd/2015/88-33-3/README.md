# Одлука о промени Статута Градске општине Барајево

Акти градских општина Барајево · 88/2015 · published 2015-12-29.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2015/88-2015.pdf#page=33) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Прописи Градске општине Барајево ускладиће се са одредбама ове одлуке у року од три месеца од дана ступања на снагу ове одлуке. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

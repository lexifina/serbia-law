# Правила Међународног такмичења музичке омладине

Акти Града · 37/2015 · published 2015-06-23.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2015/37-2015.pdf#page=6) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Ступањем на снагу ових правила престају да важе Правила Међународног такмичења музичких уметника ("Службени лист Града Београда", број 19/07). Ова правила Међународног такмичења музичке омладине ступају на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

# Статут Градске општине Врачар (пречишћен текст)

Акти градских општина Врачар · 57/2015 · published 2015-10-02.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2015/57-2015.pdf#page=4) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja (exceptions noted); source clause: Одлуке, други прописи и општи акти органа општине, пре ступања на снагу, објављују се у "Службеном листу Града Београда". Акти који се објављују ступају на снагу осмог дана од дана објављивања, осим ако, из нарочито оправданих разлога, који морају бити посебно образложени, није тим актом предвиђено да раније ступе на снагу.

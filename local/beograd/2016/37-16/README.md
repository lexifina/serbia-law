# Одлука о постављању станица за изнајмљивање бицикала на територији града Београда

Акти Града · 37/2016 · published 2016-04-28.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/37-2016.pdf#page=16) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Организациона јединица надлежна за послове саобраћаја донеће предлог плана из члана 7. ове одлуке у року од шест месеци од дана ступања на снагу ове одлуке. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

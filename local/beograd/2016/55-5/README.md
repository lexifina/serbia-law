# Одлука о промени Статута Градске општине Вождовац

Акти градских општина Вождовац · 55/2016 · published 2016-06-06.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/55-2016.pdf#page=5) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Прописи општине ускладиће се са одредбама ове одлуке у року од 90 дана од дана ступања на снагу ове одлуке. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

# Одлука о изменама Одлуке о оснивању Јавног предузећа за управљање пословним простором „Пословни центар – Раковица”

Акти градских општина Раковица · 137/2016 · published 2016-12-30.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/137-2016.pdf#page=50) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Остале опште акте надлежни органи предузећа дужни су да ускладе у року од 90 дана од дана ступања на снагу Статута предузећа. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

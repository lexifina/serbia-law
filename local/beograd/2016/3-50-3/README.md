# Одлука о начину финансирања Програма удружења из буџета Градске општине Младеновац

Акти градских општина Младеновац · 3/2016 · published 2016-02-05.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/03-2016.pdf#page=50) · [Record](tekst.md)

Date basis: narednog dana od objavljivanja; source clause: Ступањем на снагу ове одлуке престаје да важи Одлука о начину финансирања пројеката невладиних организација и млађих селекција спортских клубова из буџета Градске општине Младеновац ("Службени лист Града Београда", број 3/13 – пречишћен текст). Ова одлука ступа на снагу наредног дана од дана објављивања у "Службеном листу Града Београда".

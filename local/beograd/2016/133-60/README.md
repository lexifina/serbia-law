# Одлука о успостављању сарадње Градске општине Обреновац са градовима и општинама у сливу Колубаре

Акти градских општина Обреновац · 133/2016 · published 2016-12-29.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/133-2016.pdf#page=60) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: По ступању на снагу ове одлуке, председник градске општине Обреновац потписаће Протокол о сарадњи градова и општина у сливу Колубаре. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

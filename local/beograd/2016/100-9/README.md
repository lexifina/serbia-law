# Правила Београдског сајма књига

Акти Града · 100/2016 · published 2016-10-05.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/100-2016.pdf#page=9) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Ступањем на снагу ових правила престају да важе Правила Београдског сајма књига ("Службени лист Града Београда", број 19/07). Ова правила Београдског сајма књига ступају на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

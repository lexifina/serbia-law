# Одлука о измени и допуни Одлуке о организовању установе Спортски центар „Вождовац”

Акти градских општина Вождовац · 131/2016 · published 2016-12-29.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/131-2016.pdf#page=35) · [Record](tekst.md)

Date basis: danom objavljivanja; source clause: Установа је дужна да своја општа акта усклади са одредбама ове одлуке у року од 60 дана од дана ступања на снагу ове одлуке. Одлука ступа на снагу даном објављивања у "Службеном листу Града Београда".

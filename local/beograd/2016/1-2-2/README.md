# Одлука о подршци новорођеној деци са територије Градске општине Младеновац доделом дечјих аутоседишта категорије 0+

Акти градских општина Младеновац · 1/2016 · published 2016-01-15.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/01-2016.pdf#page=2) · [Record](tekst.md)

Date basis: narednog dana od objavljivanja; source clause: Право на дечије аутоседиште категорије 0+ предвиђено овом одлуком, може се остварити за дете рођено по ступању на снагу ове одлуке. Ова одлука ступа на снагу наредног дана од дана објављивања у "Службеном листу Града Београда".

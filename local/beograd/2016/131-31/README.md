# Одлука о финансирању активности из области образовања и васпитања из буџета Градске општине Вождовац

Акти градских општина Вождовац · 131/2016 · published 2016-12-29.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/131-2016.pdf#page=31) · [Record](tekst.md)

Одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

# Одлука о допунама Одлуке о располагању становима Града Београда

Акти Града · 37/2016 · published 2016-04-28.

Text as enacted from the official gazette; later amendments have not been consolidated.

[Official source](https://www.sllistbeograd.rs/pdf/2016/37-2016.pdf#page=25) · [Record](tekst.md)

Date basis: osmog dana od objavljivanja; source clause: Захтев из става 2. члана 1. ове одлуке може поднети лице које је почело да користи стан до дана ступања на снагу ове одлуке. Ова одлука ступа на снагу осмог дана од дана објављивања у "Службеном листу Града Београда".

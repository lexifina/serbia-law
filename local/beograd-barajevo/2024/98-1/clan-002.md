# Члан 2.
Потребна средства за финансирање буџетског дефицита у износу од 99.222.059,22 динара из члана 2. ове одлуке обезбедиће се из нераспоређеног вишка прихода из ранијих година у износу од 41.579.542,89 динара и неутрошених средства трансфера од других нивоа власти из ранијих година у износу од 57.642.516,33 динара.

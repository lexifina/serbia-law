# Члан 10.
По правноснажности решења Управе којим је утврђено право на исплату девизне штедње, Управа поништава оригинал девизне штедне књижице.
Поништени оригинал девизне штедне књижице Управа уручује девизном штедиши који је доставио оригинал девизне штедне књижице, а лицима из члана 4. став 5. ове уредбе потврду о томе да је оригинална девизна штедна књижица поништена.
Потврда из става 2. овог члана замењује поништени оригинал девизне штедне књижице и лице из члана 4. став 5. ове уредбе је ставља банци на увид приликом отварања власничког рачуна хартија од вредности и наменског девизног рачуна.

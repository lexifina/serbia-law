# Члан 14.
Министарство ће листу и одлуке из члана 13. ове уредбе доставити свим лицима са листе из члана 13. тачка 1) ове уредбе у року од десет радних дана од дана истека рока за састављање листе и доношења одлука из члана 13. ове уредбе.
Министарство ће, у року из става 1. овог члана, писаним путем обавестити лица која нису на листи из члана 13. тачка 1) ове уредбе.

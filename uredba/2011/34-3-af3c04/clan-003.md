# Члан 3.
Државни службеници из Сталне канцеларије Владе за економски развој у Бору даном престанка рада те канцеларије постају нераспоређени, у складу са законом.
Намештеницима из Сталне канцеларије Владе за економски развој у Бору престанком рада те канцеларије престаје радни однос, у складу са законом.
Решења којима се утврђује да су државни службеници из става 1. овог члана постали нераспоређени, односно да намештеницима из става 2. овог члана престаје радни однос доноси, у складу са законом, директор Службе за управљање кадровима.

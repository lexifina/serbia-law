# Члан 23.
Обвезници система из чл. 3. и 4. ове уредбе дужни су да донесу интерни акт из члана 17. ове уредбе у року од пет месеци од дана ступања на снагу ове уредбе, односно у року седам месеци од истека прве календарске године у којој су остварили годишњу потрошњу енергије изнад граничне потрошње енергије прописане овом уредбом.
Обвезници система из члана 6. ове уредбе, као и установе из члана 7. став 4. ове уредбе дужни су да донесу интерни акт из члана 17. ове уредбе у року од седам месеци од дана када су испунили критеријум за утврђивање Обвезника система у складу са овом уредбом.
Изузетно од става 1. овог члана, обвезници система који су стекли тај статус у складу са Уредбом о утврђивању граничних вредности годишње потрошње енергије на основу којих се одређује која привредна друштва су обвезници система енергетског менаџмента, годишњих циљева уштеде енергије и обрасца пријаве о оствареној потрошњи енергије ("Службени гласник РС", број 18/16), у обавези су да донесу интерни акт из члана 17. ове уредбе у року од три месеца од дана ступања на снагу ове уредбе.

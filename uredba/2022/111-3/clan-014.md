# Члан 14.
Уколико је број појединачних дозвола у одређеном прелиминарном контингенту за наредну годину мањи од збира дозвола из члана 5. ове уредбе и укупног броја дозвола из члана 13. став 4. ове уредбе, превозницима чији је број дозвола на том контингенту утврђен чланом 13. став 4. ове уредбе већи од утврђеног фиксног дела појединачног плана у години утврђивања претходног плана расподеле, број дозвола из члана 13. став 4. ове уредбе умањује се сразмерно односу утврђеном у члану 6. тачка 7) ове уредбе.
Уколико је однос утврђен у члану 6. тачка 7) ове уредбе већи од један, превозницима се укупан број дозвола из члана 13. став 4. ове уредбе, које су преостале након умањења из става 1. овог члана, умањује сразмерно односу разлике збира дозвола из члана 5. ове уредбе и броја дозвола из члана 13. став 4. ове уредбе, умањеног у складу са ставом 1. овог члана и прелиминарног контингента појединачних дозвола за наредну годину и броја дозвола из члана 13. став 4. ове уредбе.

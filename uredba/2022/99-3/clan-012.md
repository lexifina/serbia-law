# Члан 12.
Почетна годишња висина накнаде на јавном надметању за давање на коришћење државног пољопривредног земљишта једнака је:
1) петоструком износу просечне цене закупа по хектару државног пољопривредног земљишта на територији Републике Србије, у случају из члана 2. тачка 1) ове уредбе;
2) тридесетоструком износу просечне цене закупа по хектару државног пољопривредног земљишта на територији Републике Србије, у случају из члана 2. тачка 2) подтачка (1) и тачка 3) ове уредбе.
Висина накнаде за коришћење државног пољопривредног земљишта у случају из члана 2. тачка 2) подтачка (2) ове уредбе једнака је тридесетоструком износу просечне цене закупа по хектару државног пољопривредног земљишта на територији Републике Србије.

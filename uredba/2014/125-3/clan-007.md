# Члан 7.
Поступци признавања високошколских исправа започети по Уредби о посебном начину признавања високошколских исправа и вредновања студијских програма Универзитета са територије Аутономне покрајине Косово и Метохија који не обављају делатност по прописима Републике Србије ("Службени гласник РС", број 16/12) окончаће се на начин предвиђен овом уредбом.
Професионално признавање обављаће самостална високошколска установа сходно члану 4. ове уредбе, у периоду од најдуже шест месеци од дана ступања на снагу ове уредбе.

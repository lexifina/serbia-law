КОЕФИЦИЈЕНТИ РАЧУНОВОДСТВЕНИХ ОДНОСА
1. Коефицијенти краткорочне ликвидности
Текући коефицијент = текућа средства/текуће обавезе
АЦИД тест (брзи коефицијент) = (текућа средства) - залихе/текуће обавезе
Учешће нето текућих средстава у активи = (текућа средства - текуће обавезе)/актива
Краткорочне финансијске позајмице/текућа средства
Краткорочне финансијске позајмице/нето текућа средства
2. Коефицијенти дугорочне солвентности
Деонички капитал/дугорочни кредити
Покриће камата профитом = (профит+камата+порези)/камате
Проценат спољног финансирања = укупан дуг/пословна средства
Проценат сопственог финансирања фиксних средстава = сопствена средства/фиксна средства
3. Коефицијенти активности
Просечан обрт залиха = пословни приходи/залихе
Период наплаћивања = купца* 365/пословни приходи
Период плаћања = добављачи* 365/пословни расходи
Обрт активе = укупан приход/актива
Обрт фиксних средстава = укупан приход/фиксна средства
Обрт нето текућих средстава = укупан приход/нето текућа средства
4. Коефицијенти рентабилности
Бруто профит (%) = (пословни приход - пословни расход) / посл. приход
Профит пре пореза (%) = профит пре пореза/пословни приход
Нето профит (%) = нето профит/пословни приход
Принос на ангажовани капитал = нето профит/ангажовани капитал
Принос на нето средства = нето профит/(актива - текућа обавеза)
Принос на деонички капитал = нето профит/деонички капитал

# Члан 8.
На основу утврђених потреба за стручним усавршавањем из области Европске уније утврђених на начин из чл. 4. и 5. ове уредбе, Служба за ЕИ, припрема предлог програма општег стручног усавршавања.
Предлог програма општег стручног усавршавања доставља се на мишљење Високом службеничком савету, који је дужан да се о истом изјасни најкасније у року од 30 дана од дана достављања.
Директор Службе за ЕИ по прибављеном мишљењу Високог службеничког савета доноси програм општег стручног усавршавања из области Европске уније.

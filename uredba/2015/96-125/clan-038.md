# Члан 38.
Акт, предмет и евиденција из једне календарске године архивирају се по степенима тајности, у оквиру степена тајности по роковима чувања, а у оквиру рокова чувања - хронолошки, по бројевима деловодника, односно уписника.
Службена преписка с иностраним органом, чини архивску грађу и чува се трајно.

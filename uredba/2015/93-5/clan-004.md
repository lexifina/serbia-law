# Члан 4.
Начин ангажовање учесника у трагању и спасавању из члана 2. тач. 1)-4) ове уредбе врши се у складу са оперативним процедурама које израђује Директорат у складу са споразумима из члана 3. ове уредбе.
Учесници из става 1. овог члана, у складу са оперативним процедурама из става 1. овог члана, израђују сопствене оперативне процедуре.

# Члан 6.
Одговорност за тачност приказаних података у складу са овом уредбом сноси искључиво субјект из члана 2. став 3. ове уредбе, односно његов законски заступник.
Комисија из члана 4. став 4. ове уредбе искључиво врши проверу испуњености формалних услова из ове уредбе и не оцењује техничку документацију и не испитује веродостојност докумената достављених у вези са одредбама ове уредбе.

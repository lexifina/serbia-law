# Члан 25.
Дозвола за обављање производње дуванских производа издаје се, у складу са Законом, најбоље рангираном учеснику на јавном тендеру.
Изузетно, најбоље рангираном учеснику може се издати привремена дозвола којом ће се одредити рок за испуњење услова из члана 22. став 1. Закона који је наведен у понуди.
По испуњењу услова у року из става 2. овог члана, лице коме је издата привремена дозвола о томе обавештава Агенцију, која је дужна да по пријему обавештења покрене поступак за издавање дозволе из става 1. овог члана, у складу са Законом.
У случају да лице коме је издата привремена дозвола не испуни услове из члана 22. став 1. Закона у року из става 2. овог члана, привремена дозвола престаје да важи.

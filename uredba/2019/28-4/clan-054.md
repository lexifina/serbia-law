# Члан 54.
За сва лица која испуњавају услове, претпостављени старешина предлог за унапређење подноси редовним путем надлежном старешини који га посебно образлаже и документује.
Образац Предлога за унапређење дат је у Прилогу 4. ове уредбе и чини њен саставни део.
Предлог за унапређење, по правилу, доставља се 30 дана пре дана испуњења услова за унапређење.
Официр, подофицир, односно професионални војник по уговору на неодређено време, по правилу унапређује се у виши чин са даном испуњења услова за унапређење.
У случају да официр, подофицир, односно професионални војник по уговору на неодређено време из става 4. овог члана не буде унапређен у виши чин са даном испуњења услова за унапређење, старешина надлежан за унапређење унапредиће га са даном доношења акта о унапређењу.

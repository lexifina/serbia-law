# Члан 52.
Официр, подофицир, односно професионални војник по уговору на неодређено време код којег је наступило умањење способности за професионалну војну службу као непосредна последица учешћа у борбеним операцијама може, по овом основу, бити једном у току службе ванредно унапређен у непосредно виши чин, ако испуњава опште услове за унапређење у виши чин из члана 55. став 1. тач. 2), 3) и 4) Закона.

# Члан 17.
Гранични ниво за размену средстава обезбеђења треба да буде нула.
У погледу оперативних аспеката привремена одступања од граничног нивоа су дозвољена.
Међусобно договорени независни износи договарају се у Анексу кредитне подршке (CSA).
Минимални износ средстава обезбеђења је износ који је договорен са другом уговорном страном у Анексу кредитне подршке (CSA).

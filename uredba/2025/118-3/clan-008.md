# Члан 8.
Корисник коме су додељена средства подстицаја је дужан да прибави решење о категоризацији хотела у року од две годинe, рачунајући од дана уплате средстава подстицаја.
Категорија хотела из става 1. овог члана не може бити нижа од четири звездице (4*), која се одређује сагласно прописима из области угоститељства.
Услов обављања угоститељске делатности у категорији хотела из става 2. овог члана Корисник обезбеђује у периоду од најмање десет година, рачунајући од дана отварања хотела.

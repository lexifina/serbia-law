# Члан 3.
Основица накнаде за коришћење земљишта у државној својини у нешумске намене је:
1. површина земљишта изражена у метрима квадратним (m2) за намене из члана 2. став 2. тачка 1), 2) и 4),
2. површина земљишта изражена у метрима квадратним (m2), односно дужинама изражена у m за намене из члана 2. став 2. тачка 3),
3. број привеза за намене из члана 63. став 2. тачка 5),
4. запремина изражена у метрима кубним (m3), маса изражена у тонама (t), односно број возила за намеме из члана 63. став 2. тачка 6).

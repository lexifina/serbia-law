# Члан 193.
По предметима хитне природе (притвор и сл.), одлуке се доносе одмах, водећи рачуна о природи ствари и прописаним роковима поступка.
По тужбама, предлозима за извршење и другим предлозима који се могу брзо решити, доноси се одлука и предаје писарници по правилу истог дана кад су ти поднесци примљени, при чему би требало имати у виду прописе о првенству решавања.
Предмети по којима су одржана рочишта и по којима је донета одлука за даље поступање, враћају се писарници истог, а најкасније следећег дана, ради развођења по уписницима и поступања по одлуци.

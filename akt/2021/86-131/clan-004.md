# Члан 4.
Извод из бирачког списка сачињава Изборна комисија за свако бирачко место, за сваки суд који је одређен да гласа на том бирачком месту.
Извод из бирачког списка мора бити оверен.
Извод из бирачког списка се оверава тако што се на последњој страни сваког бирачког списка наводе подаци из решења о закључењу бирачког списка, а посебно број страна извода из бирачког списка, број судија бирача, датум закључења извода, потпис овлашћеног лица и печат Изборне комисије.

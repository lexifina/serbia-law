# Члан 22.
Клуб чланова Скупштине Коморе из огранка чине сви чланови Скупштине Коморе из огранка.
Клуб чланова Скупштине Коморе из огранка састаје се по потреби а најмање једанпут годишње.
О појединим питањима Одбор огранка може писаним путем достављати информације и прибављати мишљења чланова Скупштине са огранка.
Клуб чланова Скупштине Коморе из огранка сазива председник Одбора огранка на своју иницијативу или најмање 1/3 чланова Скупштине Коморе из огранка.
Клуб чланова Скупштине Коморе из огранка пуноважно ради ако је седници присутно више од половине чланова, а одлуке доноси већином гласова присутних чланова.

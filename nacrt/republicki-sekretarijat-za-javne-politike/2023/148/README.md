## Description on the portal

Уредбом о поступку припреме Нацрта плана развоја Републике Србије се уређује поступак израде хијерархијски највишег развојног документа који усваја Народна Скупштина. У складу са Законом о планском систему, Влада прописује поступак припреме Плана развоја на предлог органа државне управе надлежног за координацију јавних политика. За израду наведене уредбе основана је Радна група чији рад је планиран у периоду од 15. 03. 2023. - 31.05. 2023. године. Уређивање постпка припреме Нацрта плана развоја представља предуслов за започињање рада на изради овог документа, који подразумева и утврђивање садржаја Плана развоја који ближе уређује Народна Скупштина на предлог Владе.

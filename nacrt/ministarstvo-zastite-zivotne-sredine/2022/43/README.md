## Description on the portal

Министарство заштите животне средине, у складу са одредбама члана 32. Закона о планском систему Републике Србије (''Службени гласник РС'', број 30/18), обавештава заинтересовану јавност о почетку израде нацрта Акционог плана Програма управљања отпадом у Републици Србији за период од 2022. до 2031. године, ради остваривања циљева и праћења Програма.

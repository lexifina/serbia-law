## Description on the portal

Министарство заштите животне средине је дана 21. јануара 2022. године расписало Јавни конкурс за доделу средстава за суфинансирање реализације пројеката смањења загађења ваздуха у Србији из индивидуалних извора. На Јавни конкурс пристигло је укупно 33 пријаве.

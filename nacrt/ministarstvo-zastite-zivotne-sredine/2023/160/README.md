## Description on the portal

Министарство заштите животне средине је дана 1. марта 2023. године расписало Јавни конкурс за доделу средстава за суфинансирање реализације пројеката изградње система управљања отпадом у 2023. години, а за доделу средстава за изградњу система управљања отпадом који су у надлежности јединица локалне самоуправе. На Јавни конкурс пристигло је укупно 5 пријава.

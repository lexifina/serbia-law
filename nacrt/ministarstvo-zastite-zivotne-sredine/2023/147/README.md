## Description on the portal

Министарство заштите животне средине донело je Одлуку о додели подстицајних средстава по Јавном конкурсу за четврти квартал 2022. године, број 401-00-00105/1/2023-06 од 8. марта 2023. године. На основу сагласности добијене од Министарства финансија број 401-00-7466/2022-03 од 9. марта 2023. године, којом су ово министарство обавестили да су сагласни са преузимањем обавеза наведених у Обрасцу ЗПО у укупном износу од 140.102.727,49 динара, измењена је горе наведена одлука на начин да се корисницима подстицајних средстава исплаћује пун износ подстицајних средстава, на начин како је приказано у Табели у Глави I ове одлуке.

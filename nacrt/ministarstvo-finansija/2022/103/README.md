# Програм економских реформи 2023-2025.

A draft in public consultation on the eKonsultacije portal (ekonsultacije.gov.rs). Not law.

- Initiator: Министарство финансија
- Document type: Остало
- Area: Конкурентност
- Opened on the portal: 2022-12-12
- Phase when collected: Консултације (process ended)
- Portal page: <https://ekonsultacije.gov.rs/topicOfDiscussionPage/103/1>
- Collected: 2026-11-14

## Description on the portal

Република Србија, као држава кандидат за пријем у чланство ЕУ, у претприступном периоду на годишњем нивоу израђује документ под називом Програм економских реформи који представља стратешки документ за планирање економске политике и управљање реформама, кључних како за побољшање конкурентности, подстицање нових радних места и олакшавање социјалне инклузије, тако и за испуњавање економских критеријума у ​​процесу приступања ЕУ.

# Члан 46.
По захтевима поднетим за исељење носилаца станарског права из станова у својини грађана, по члану 37. Закона о стамбеним односима који је престао да важи даном ступања на снагу овог закона, по којима није донето првостепено решење, решаваће се по овом закону.
Ако захтеви за исељење носиоца станарског права нису поднети у смислу става 1. овог члана, могу се поднети у року од 90 дана од дана ступања на снагу овог закона.

# Члан 50.
По жалбама на решења органа општине надлежног за стамбене послове, одлучује министарство надлежно за стамбене послове.
Аутономној Покрајини Војводини поверава се решавање по жалби против првостепеног решења општинске управе општине која се налази на територији Аутономне Покрајине Војводине.
Граду Београду поверава се решавање по жалби против првостепеног решења које се доноси у складу са одредбама овог закона.

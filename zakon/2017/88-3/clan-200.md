# Члан 200.
Министар ће донети подзаконске акте у року од годину дана од дана ступања на снагу овог закона, осим акта из члана 187. став 4. овог закона који ће донети у року од шест месеци од дана ступања на снагу овог закона, до када висину средстава из члана 187. став 2. тач. 1)-3) овог закона, министар утврђује решењем.

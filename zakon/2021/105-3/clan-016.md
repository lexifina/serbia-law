# Члан 16.
У случају престанка функције Заштитника грађана из разлога наведених у члану 13. став 1. тач. 2)-6) овог закона, Народна скупштина, без расправе, доноси одлуку којом утврђује дан престанка функције.
Правне последице престанка функције наступају од дана престанка функције утврђеног у одлуци из става 1. овог члана.

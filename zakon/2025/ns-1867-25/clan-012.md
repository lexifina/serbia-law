# Члан 12.
У члану 109. после става 2. додаје се нови став 3, који гласи:
„(3) Изузетно од става 2. овог члана, обнова катастра непокретности према подацима комасационог премера врши се по пријему елабората реализације геодетско-техничких радова у поступку комасације од стране Завода, а на основу правноснажних решења о расподели комасационе масе без спровођења поступка излагања.”
Досадашњи став 3. постаје став 4.

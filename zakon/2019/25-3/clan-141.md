# Члан 141.
Изабрани лекар дужан је да прими свако осигурано лице које га изабере, осим ако је код тог изабраног лекара евидентиран број осигураних лица већи од утврђеног стандарда броја осигураних лица по једном изабраном лекару.
Стандард броја осигураних лица по једном изабраном лекару утврђује министар.

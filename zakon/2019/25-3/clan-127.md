# Члан 127.
Осигурано лице, за које нису уплаћени доприноси, а користи здравствену заштиту, сноси трошкове те здравствене заштите из својих средстава, осим у случајевима из члана 125. став 4. овог закона.
Уколико обвезник уплате доприноса није извршио уплату доприноса, осигурано лице има право на накнаду плаћених трошкова за пружену здравствену заштиту из става 1. овог члана од обвезника уплате доприноса за обавезно здравствено осигурање.

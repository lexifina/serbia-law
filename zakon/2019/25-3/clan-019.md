# Члан 19.
Супружник има права из обавезног здравственог осигурања док је са осигураником у браку у смислу прописа о породици.
Ванбрачни партнер осигураника има права из обавезног здравственог осигурања од дана подношења пријаве на осигурање у својству члана уже породице у складу са овим законом.
Супружник којем је по престанку брака судском одлуком утврђено право на издржавање има права из обавезног здравственог осигурања за период док траје обавеза издражавања.

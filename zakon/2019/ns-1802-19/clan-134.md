# Члан 134.
Центри изузетних вредности који су тај статус стекли по прописима који су важили до ступања на снагу овог закона задржавају тај статус до истека времена на који је статус стечен.
Питање финансирања центара из става 1. овог члана уредиће се Програмом из члана 12. став 3. тачка 4) овог закона.

# Члан 133.
Институти од националног значаја који су тај статус стекли по прописима који су важили до ступања на снагу овог закона задржавају тај статус до истека времена на који је статус стечен.
Питање финансирања института из става 1. овог члана уредиће се Програмом из члана 12. став 2. тачка 2) овог закона.

# Члан 207.
Трошкове обдукције умрлог лица сноси обвезник плаћања трошкова лечења умрлог лица, ако овим законом није другачије уређено.
Трошкове обдукције умрлог лица из члана 206. став 2. тачка 5) овог закона сноси јединица локалне самоуправе.
Трошкове обдукције умрлог лица из члана 206. став 2. тач. 7) и 8) овог закона сноси подносилац захтева.

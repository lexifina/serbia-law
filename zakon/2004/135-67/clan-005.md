# Члан 5.
Одлуку о издавању обвезница из члана 4. овог закона донеће Влада Републике Србије, у року од осам дана од дана ступања на снагу овог закона.
Одлуком из става 1. овог члана, прописаће се основни елементи обвезница из члана 4. овог закона, као и ближи услови њиховог издавања, секундарног промета и исплате.

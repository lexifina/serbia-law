# Члан 6.
Ради измиривања обавеза из овог закона, Република Србија дужна је да обезбеђује средства за уредну отплату обавеза по Споразуму о кредиту за развој из члана 2. овог закона, а у складу са Уредбом о преносу средстава из члана 3. овог закона.
Средства из става 1. овог члана Република Србија преноси на посебан рачун Србије и Црне Горе код Народне банке Србије, са искључивом наменом отплате обавеза из Споразума о кредиту за развој из члана 2. овог закона.

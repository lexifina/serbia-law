# Члан 16.
Грађанин одјављује боравиште надлежном органу по месту боравишта, непосредно пре одласка из места боравишта.
Лицу које одјављује боравиште издаје се одговарајућа потврда.
Ако грађанин не одјави боравиште, сматра се да је боравиште престало пошто истекне време наведено у пријави.
Ако у пријави није наведено време трајања боравка, а боравиште није одјављено, пријава боравишта важи две године од дана пријаве, након чега је грађанин дужан да поново пријави боравиште ако и даље борави у месту у коме је имао пријављено боравиште.

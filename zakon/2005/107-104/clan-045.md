# Члан 45.
Прекурсори који су предмет привредних преступа и прекршаја одузеће се.
Прекурсори из става 1. овог члана и прекурсори одузети из илегалних токова, третирају се, односно уништавају као отпад, у складу са прописима којима се уређује управљање отпадом.
Влада прописује ближе услове за поступање са одузетим прекурсорима из става 2. овог члана.
Влада образује Комисију за контролу поступка уништавања прекурсора.
Чланови Комисије из става 4. овог члана немају право на новчану надокнаду за рад у Комисији.

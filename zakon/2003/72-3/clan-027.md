# Члан 27.
Функционери оставку подносе Народној скупштини и дужни су да о поднетој оставци без одлагања обавесте Савет.
Функционеру који је поднео оставку функција престаје избором новог, а најкасније истеком 90 дана од дана подношења оставке, осим у случају из члана 26. став 4. овог закона.
Одбор за финансије констатује престанак функције функционера Народне банке Србије.

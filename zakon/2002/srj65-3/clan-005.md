# Члан 5.
Ради измирења обавеза по Споразуму из члана 2. овог закона Република Србија даће Савезној Републици Југославији контрагаранцију за уредно обезбеђење средстава за измирење обавеза по том споразуму.
Контрагаранцијом Република Србија се обавезује да у свакој години обезбеди средства у свом буџету за измиривање обавеза по основу уговора из члана 2. овог закона, а које доспевају у тој години, уколико то не учини корисник кредита.
Средства из става 1. овог члана, корисник кредита, односно Република Србија ће пренети на посебан рачун код Војвођанске банке, а.д. Нови Сад са искључивом наменом отплате кредита из члана 2. овог закона.
Средства из става 3. овог члана, не чине део савезног буџета.

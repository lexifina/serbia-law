# Члан 5.
Ради измиривања обавеза из овог закона, Савезна Република Југославија и Република Црна Гора у складу са одредбама Споразума из члана 2. овог закона су дужне да обезбеђују средства за уредну отплату обавеза по Споразуму из члана 2. овог закона, а у складу са Споразумом из члана 4. став 2. овог закона.
Средства из става 1. овог члана Савезна Република Југославија и Република Црна Гора у складу са одредбама споразума из члана 2. овог закона преносе на посебне рачуне Савезне Републике Југославије код Народне банке Југославије, са искључивом наменом отплате обавеза из овог закона.

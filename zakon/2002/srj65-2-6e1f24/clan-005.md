# Члан 5.
Ради измиривања обавеза из овог закона, Република Србија је дужна да обезбеђује средства за уредну отплату обавеза по Писму о споразуму из члана 2, а у складу са уговором из члана 4. став 2. овог закона.
Средства из става 1. овог члана Република Србија преноси на посебан рачун Савезне Републике Југославије код Народне банке Југославије, са искључивом наменом отплате обавеза из овог закона.

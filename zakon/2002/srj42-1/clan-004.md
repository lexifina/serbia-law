# Члан 4.
Ради измиривања обавеза по уговору из члана 2. овог закона Република Србија даће Савезној Републици Југославији контрагаранцију за уредно обезбеђење средстава за измиривање обавеза по том уговору за дугове предузећа са њене територије.
Контрагаранцијом Република Србија се обавезује да у свакој години обезбеди средства у свом буџету за измирење обавеза по основу уговора из члана 2. овог закона, које доспевају у тој години, уколико то не учини корисник зајма.
Средства из става 2. овог члана Република Србија преноси на посебан рачун Савезне Републике Југославије код Народне банке Југославије са искључивом наменом отплате зајма из члана 2. овог закона.
Средства из става 3. овог члана не чине део савезног буџета.

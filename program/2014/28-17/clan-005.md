# Члан 5.
Кандидати који су до дана ступања на снагу Закона о ревизији ("Службени гласник РС", број 62/13) започели полагање испита по програму Коморе за стицање звања овлашћени ревизор, могу да полажу преостале испите по програму по којем су започели полагање тог испита, најкасније у року од три године од дана ступања на снагу тог закона.
